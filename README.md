# PurrCat101

A modern technical blog built with Next.js and Contentlayer for MDX content management.

## Site URL

original from https://webtech-note.com/

## Tech Stack

- **Framework**: Next.js
- **Content**: MDX with Contentlayer
- **Styling**: CSS Modules
- **Deployment**: Vercel
- **Comments**: Giscus
- **Search**: Kbar Command Palette

## Project Structure

```text
├── components/       # React components
│   ├── blog/         # Blog-specific components
│   └── layout/       # Layout components
├── pages/            # Next.js pages
│   ├── api/          # API routes
│   └── posts/        # Blog post pages
├── posts/            # MDX blog posts
│   └── draft/        # Draft posts
├── public/           # Static assets
├── styles/           # Global styles
└── utils/            # Utility functions
```
