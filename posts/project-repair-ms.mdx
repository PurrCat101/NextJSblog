### Handle submit form

1. เมื่อเจอ error ให้ทำการแจ้ง error
2. ถ้า login สำเร็จให้ไปหน้า Homepage

<CodeHead lang="jsx" />

```jsx
const handleSubmit = async (e) => {
  e.preventDefault();
  setError("");
  setIsLoading(true);

  try {
    // 1. Sign in with Supabase
    const { error } = await supabase.auth.signInWithPassword({
      email,
      password,
    });

    // 2. If error occurs, throw it
    if (error) throw error;

    // 3. If successful, redirect to home page
    navigate("/");
  } catch (error) {
    setError(error.message || "Login failed");
  } finally {
    setIsLoading(false);
  }
};
```

## การทำ Filter

สร้าง input box สำหรับค้นหาข้อมูล
เมื่อ user ทำการพิมพ์ข้อความใน input box ค่าที่พิมพ์จะถูกเก็บไว้ใน `searchTerm` เพื่อนำไปใช้ในการค้นหาข้อมูล

<CodeHead lang="jsx" />

```jsx
const [searchTerm, setSearchTerm] = useState("");

<input
  type="text"
  value={searchTerm}
  onChange={(e) => setSearchTerm(e.target.value)}
  placeholder="Search logs..."
  className="w-full pl-10 pr-4 py-2 border rounded-lg"
/>;
```

ในการทำ filter ข้อมูลจะใช้ `useEffect` โดยจะทำการเรียก function `fetchRepairTasks` เมื่อค่าใน `searchTerm` มีการเปลี่ยนแปลง

<CodeHead lang="jsx" />
```jsx
useEffect(() => {
  if (!initialLoading) {
    fetchRepairTasks();
  }
}, [searchTerm, startDate, endDate, dateField]);
```

โดย function `fetchRepairTasks` จะทำการเรียกข้อมูลทั้งหมดจาก database และทำการ filter ข้อมูลโดยใช้ค่าที่อยู่ใน `searchTerm` และทำการเรียกใช้ function นี้เมื่อมีการเปลี่ยนแปลงค่าใน `searchTerm`

<CodeHead lang="jsx" />
```jsx
if (searchTerm) {
  query = query.or(
    `device_name.ilike.%${searchTerm}%,issue.ilike.%${searchTerm}%`
  );
}
```
โดยเป็น syntax ของ Supabase JavaScript Client Library (supabase-js) ในการทำการ filter ข้อมูลสามารถทียบกับ SQL ได้ดังนี้

<CodeHead lang="" />

```sql
SELECT * FROM repair_tasks WHERE device_name ILIKE '%searchTerm%' OR issue ILIKE '%searchTerm%'
```

### การกรองด้วยวันที่ (Date Filter)

เมื่อเลือกวันที่ setStartDate หรือ setEndDate จะทำการเรียก function fetchRepairTasks โดยจะทำการ filter ข้อมูลโดยใช้วันที่ที่เลือก

<CodeHead lang="jsx" />
```jsx
<DatePicker
  selected={startDate}
  onChange={setStartDate}
  placeholderText="Start date"
  className="border rounded-lg p-2"
/>
```

โดย query ที่ใช้ในการ filter ข้อมูลด้วยวันที่จะมีการเปลี่ยนแปลงตามวันที่ที่เลือก

1. กรองข้อมูล startDate เป็นต้นไป (gte) greater than or equal
2. กรองข้อมูล endDate ถึงวันถัดไป (lt) less than

เมื่อเลือกวันที่ endDate จะทำการบวก 1 วันเพื่อเพื่อให้ระบบทำการกรองข้อมูลถึงวันสุดท้ายที่เลือกได้เนื่องจาก query ด้วย less than คือหมายถึงน้อยกว่าวันที่เลือก(ปรับเป็น less than or equal ก็ได้จะได้ไม่ต้องบวก 1 วัน)

<CodeHead lang="jsx" />
```jsx
if (startDate) {
  query = query.gte(dateField, startDate.toISOString());
}
if (endDate) {
  const nextDay = new Date(endDate);
  nextDay.setDate(nextDay.getDate() + 1);
  query = query.lt(dateField, nextDay.toISOString());
}
```

### การล้างตัวกรอง (Clear Filters)

เมื่อ user ต้องการล้างตัวกรอง สามารถทำการเรียกใช้ function `clearFilters` ซึ่งจะทำการล้างค่าทั้งหมดใน `searchTerm`, `startDate`, `endDate`, `dateField` ที่อยู่ใน state

<CodeHead lang="jsx" />
```jsx
const clearFilters = () => {
  setStartDate(null);
  setEndDate(null);
  setDateField("created_at");
  setSearchTerm("");
};
```
