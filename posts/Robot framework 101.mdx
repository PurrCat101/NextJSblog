# การใช้ Robot Framework สำหรับ Automated Testing

Robot Framework เป็นเครื่องมือที่ใช้ในการทำ Automated Testing ที่มีความยืดหยุ่นและสามารถใช้งานได้ง่าย โดยเฉพาะสำหรับการทดสอบระบบที่มีการพัฒนาอย่างรวดเร็ว ในบทความนี้เราจะพูดถึงการติดตั้ง Robot Framework, โครงสร้างของโปรเจ็ค, ไฟล์ต่างๆ และ syntax ที่ใช้ในการเขียน test cases

## การติดตั้ง Robot Framework

การติดตั้ง Robot Framework สามารถทำได้ง่ายๆ ผ่าน Python Package Manager (pip) โดยทำตามขั้นตอนดังนี้:

1. **ติดตั้ง Python**: หากยังไม่มี Python ติดตั้งในเครื่อง สามารถดาวน์โหลดได้ที่ [python.org](https://www.python.org/downloads/)

2. **ติดตั้ง Robot Framework**: เปิด Command Prompt หรือ Terminal แล้วรันคำสั่งต่อไปนี้:

<CodeHead lang="console" />

```console
pip install robotframework
```

3. **ตรวจสอบการติดตั้ง**: หลังจากติดตั้งเสร็จแล้ว สามารถตรวจสอบได้โดยการรันคำสั่ง:

<CodeHead lang="console" />

```console
robot --version
```

## โครงสร้างของโปรเจ็ค

Simple project structure
[Project structure](https://docs.robotframework.org/docs/examples/project_structure)

<CodeHead lang="" />

```structure
my_project
├── tests
│   ├── suiteA.robot
│   ├── suiteB.robot
│   ├── ...
│
├── resources
│   ├── common.resource
│   ├── some_other.resource
│   ├── custom_library.py
│   ├── variables.py
│   ├── ...
│
├── .gitlab-ci.yml
├── .gitignore
├── README.md
├── requirements.txt
```

### อธิบายไฟล์ต่างๆ

- **tests/**: โฟลเดอร์นี้ใช้เก็บไฟล์ test cases ที่คุณสร้างขึ้น โดยไฟล์ที่มีนามสกุล `.robot` จะเป็นไฟล์ที่ใช้ในการเขียน test cases

- **resources/**: โฟลเดอร์นี้ใช้เก็บไฟล์ที่เกี่ยวข้องกับการทดสอบ เช่น คีย์เวิร์ดที่กำหนดเองและตัวแปรที่ใช้ใน test cases

  - **keywords/**: เก็บไฟล์ที่มีการกำหนดคีย์เวิร์ดที่ใช้ใน test cases
  - **variables/**: เก็บไฟล์ที่มีการกำหนดตัวแปรที่ใช้ใน test cases

- **README.md**: ไฟล์นี้ใช้สำหรับอธิบายโปรเจ็คและวิธีการใช้งาน

## Syntax ของ Robot Framework

Robot Framework ใช้ syntax ที่อ่านง่ายและเข้าใจได้ง่าย โดยมีโครงสร้างหลักๆ ดังนี้:

### Test Case

<CodeHead lang="" />

```robot
*** Test Cases ***
Example Test Case
    [Documentation]    This is an example test case
    Open Browser       https://example.com    chrome
    Title Should Be    Example Domain
    Close Browser
```

### Keyword

<CodeHead lang="" />

```robot
*** Keywords ***
Open Browser
    [Arguments]     ${url}    ${browser}
    Open Browser    ${url}    ${browser}
```

### Variable

<CodeHead lang="" />

```robot
*** Variables ***
${URL}        https://example.com
${BROWSER}    chrome
```

### Style Procedural vs Gherkin

Robot Framework รองรับทั้งสไตล์การเขียนแบบ Procedural และ Gherkin:

- **Procedural**: เขียนตามลำดับขั้นตอน
- **Gherkin**: ใช้รูปแบบ Given-When-Then

<CodeHead lang="" />

```robot
*** Test Cases ***
Given I am on the Google page
    Open Browser    https://www.google.com    chrome
When I search for Robot Framework
    Input Text    name=q    Robot Framework
Then I should see results
    Page Should Contain    Robot Framework
```

## Create a simple test case

ไฟล์ `suiteA.robot`

<CodeHead lang="" />

```robot
*** Settings ***
Resource    ../resources/common.resource
Resource    ../resources/some_other.resource

*** Test Cases ***
Test Case A
    [Documentation]    This is a test case in Suite A
    Log    Hello from Suite A!
    Log Message    This is a message from Test Case A

Test Case B
    [Documentation]    Another test case in Suite A
    Log    This is another test case.
    Print Hello
```

ไฟล์ `suiteB.robot`

<CodeHead lang="" />

```robot
*** Settings ***
Resource    ../resources/common.resource
Resource    ../resources/some_other.resource

*** Test Cases ***
Test Case C
    [Documentation]    This is a test case in Suite B
    Log    Hello from Suite B!
    Log Message    This is a message from Test Case C

Test Case D
    [Documentation]    Another test case in Suite B
    Log    This is another test case.
    Print Hello
```

ไฟล์ `common.resource`

<CodeHead lang="" />

```robot
*** Keywords ***
Log Message
    [Arguments]    ${message}
    Log    ${message}
```
